# Roadmap

## Phase 0 — Foundation

- Rust workspace
- Tauri shell
- typed IPC
- configuration loading
- SQLite
- audit foundation
- resource monitor

## Phase 1 — Safe Agent Core

- single primary agent
- model provider abstraction
- read-only tools
- task state machine
- evidence model

## Phase 2 — Controlled Actions

- capability permissions
- approval UI
- scoped filesystem writes
- structured process execution
- rollback where feasible

## Phase 3 — Mini-ROCKYs

- task decomposition
- worker scheduler
- bounded concurrency
- blackboard findings
- cancellation

## Phase 4 — Rich Computing Tools

- browser adapter
- developer tooling
- application integrations

## Phase 5 — Advanced Security

- stronger sandboxing per platform
- hardened executors
- plugin/tool signing strategy

## Phase 6 — Intelligence

- memory retrieval
- model routing
- proactive suggestions under strict privacy policy

No phase may weaken the constitution's invariants.
